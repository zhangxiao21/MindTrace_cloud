# 心迹 0.4.2 变更说明

日期：2026-11-13 · 分支：`0.4.2` · versionCode 17 / versionName 0.4.2

本版本以 `0.4.2` 分支（含 0.4.1 全部功能）为基线，合并 `main` 分支的云备份能力，并做了主题、问卷、备份格式与界面入口的整理。**尚未发布正式签名 APK**。

---

## 一、合并 main 分支的云同步功能

| 内容 | 说明 |
| --- | --- |
| 云备份传输 | `CloudBackupClient`：WebDAV（HTTPS PUT / GET / MKCOL）、Gitee / GitHub Contents API，全部使用系统 `HttpURLConnection`，无第三方网络库 |
| 凭据存储 | `CloudBackupStore`：非敏感字段在应用私有 SharedPreferences；WebDAV 密码 / Git 令牌用 Android Keystore 中不可导出的 AES-GCM 密钥加密 |
| 界面 | `CloudBackupScreen`：平台切换、连接配置、保存配置、上传、下载恢复、清除配置，恢复前二次确认 |
| 权限 | 新增 `INTERNET`；`usesCleartextTraffic=false` 保持不变，WebDAV 强制 HTTPS |
| 触发方式 | **只有手动点击上传 / 下载才联网**，没有账号、自动同步、广告或统计 SDK |

云备份上传 / 下载的都是本机加密后的 `.mtrbackup`，与「导出加密备份」是同一格式；备份密码从不保存。

合并时**保留 0.4.2 分支的全部能力**：服药补记（含未来日期双重校验）、281 条药物预设、长按拖拽排序、18 个紧急支持地区、赞助与作者的话、科普英文、5 套主题色、截图与 0.4.0 / 0.4.1 发布说明。同时并入 main 的 `buildToolsVersion = "34.0.0"`，避免无网络环境下自动下载未安装的 Build Tools。

## 二、新增主题切换

- **首页快捷按钮**：一键在浅色 / 深色之间切换，带 Toast 反馈；跟随系统模式下按当前系统深色状态决定切换方向。
- **设置页统一面板**：「我的 → 右上角齿轮 → 外观与主题」打开切换面板，可选跟随系统 / 浅色 / 深色、5 套主题色，并有即时预览与「一键切换」按钮。
- **单一数据源**：模式与色值集中在 `ui/theme/Theme.kt` 的 `ThemeModeOptions` / `ThemeColorOptions`，设置页、切换面板、备份恢复校验共用，避免多处重复维护。
- 切换立即生效，不需要重启；主题设置随 0.4.2 备份一起恢复。

## 五、备份格式 v2：加密云账号信息，兼容旧版备份

- 新增 `BackupSettings` 与 `BackupCloudConfig`，随加密备份一起导出：界面语言 / 深浅模式 / 主题色 / 紧急支持地区 / 药物排序 / 报告天数 / 通知脱敏，以及云备份的平台、地址、账号、仓库、分支、路径、密码 / 令牌。
- **凭据二次加密**：WebDAV 密码与 Git 令牌先由「备份密码派生的密钥 + 独立随机 IV」的 AES-GCM 单独包裹，再写入整体加密的 payload；即使解密后的 JSON 也不含明文凭据。恢复时解密后交给新设备的 `CloudBackupStore` 用本机 Keystore 重新加密。
- **文件头**：新版 `MTR\x02`，旧版 `MTR\x01`。`decrypt` 同时接受两种文件头，`BackupPayload.version` 允许 1..2。
- **完全兼容旧备份**：0.4.1 及更早版本导出的 `.mtrbackup` 仍可直接导入；缺失的 `settings` / `cloudBackup` 字段走 `null` 默认值，**不会覆盖本机现有的界面设置与云配置**。反向不兼容：旧版应用无法读取 v2 备份。
- 备份仍**不包含** PIN、生物识别设置、提醒开关与时间、数据库密钥、Keystore 密钥、备份密码本身。
- 恢复成功后同步刷新内存中的设置、通知渠道与提醒。

## 六、补记能力核查（同版本后续提交）

逐类确认「过去任意一天的信息能否补全」，并修掉 4 个缺口：

| 类别 | 核查结果 | 修正 |
| --- | --- | --- |
| 打卡（心情、睡眠时长 / 质量、焦虑、症状强度、备注等） | 任意过去日期可写全部字段；`check_ins.date` 唯一索引 + 仓库按日期取 id 再 upsert，不会补出重复行 | 补记时按钮改为「保存补记」 |
| 服药 | 原来按 `active` + 起止日期过滤，导致「先吃药、后补录药物」时历史剂量列不出来 | 新增 `selectDoseMedications()`：历史日期列出全部定时药物（含已停用 / 起止日期之外），今天仍按原规则；按需药物补记也不再要求在服 |
| 量表 | 原来只有 `createdAt`，结果只能算作今天，**无法补记** | 最后一题新增「记录日期」选择器，用 `createdAt` 承载所选日期时间；趋势 / 最近测评 / 复诊报告本来就按 `createdAt` 取日期，**无需改数据库 schema** |
| 日记 | 日期可改，支持过去日期 | 无需改动 |

其他修正：
- 日历翻月自动选中新月份对应日期（原来翻到 10 月后点「补记」仍会写进今天），并禁止进入未来月份。
- 打卡、日记仓库层补充未来日期拒绝；量表在 ViewModel 兜底回退到今天；服药补记原本已有双重校验。
- 新增 `BackfillTest`（4 项），中英文文案同步；`TESTING.md` 增加补记核查清单。
